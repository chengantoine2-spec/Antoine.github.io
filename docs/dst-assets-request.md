## 二、放哪、怎么命名（最关键的一段）

仓库：`chengantoine2-spec/Antoine.github.io`，分支：`img`

```
img 分支
└── dst/                 ← 新建这个目录
    ├── wilson.png
    ├── golden-axe.png
    ├── ham-bat.png
    ├── spider.png
    └── ...
```

**规则：`dst/<条目 id>.<扩展名>`，目录扁平、不嵌套。**

为什么必须是这个形式：

- **独立 `dst/` 目录**：img 分支根下现在是 `YYYY/MM/<随机16位>.png` 的博客图片约定。
  素材混进去之后，"哪些是博客图、哪些是 wiki 素材"就分不出来了，以后批量换图或清缓存无从下手
- **文件名 = 条目 id**：我的数据里已经有稳定 id（`src/data/dst/*.ts`），
  文件名对上 id 就能**纯自动**接上；否则要手写 104 行映射表，且改一次名就断一次
- **扁平不嵌套**：我按"文件名去扩展名"取 id，多一层目录会让规则变复杂

条目 id 清单：**完整清单在 [`docs/dst-assets-id-list.md`](./dst-assets-id-list.md)**

## 三、格式与规格

| 项 | 要求 | 为什么 |
|---|---|---|
| 格式 | **PNG，带透明底** | 游戏素材本来就带 alpha。白底方图在深色主题（`night`）下会变成一块块白斑 |
| 边长 | **128~256 px** | 卡片显示约 40px、详情约 96px，再大只是浪费流量 |
| 尺寸 | 尽量统一；不统一也行 | 我会用 `object-fit` 兜住，只是统一了更好看 |
| 一图一文件 | 是 | 我要按 id 取单张，雪碧图用不了 |
| 扩展名 | 随意（`.png` 最好） | 我按 `<id>.<任意扩展名>` 匹配；**希望同一批保持一致**，方便我写死一个后缀 |

⚠️ **不要把 PAT 贴进会话记录**。这个会话里已经有过一次教训：用户给的 PAT 出现在记录里，发完就得撤销重建。你要写文档的话，**文档里也别放 token**。

## 六、两个坑，先说清

**jsDelivr 有缓存**

素材传上去后 CDN 不会立刻认。两种情况：

- **换新文件名**（哪怕同名只是改了内容）：CDN 会当成新资源，没问题
- **覆盖同名文件**：CDN 可能继续吐旧图，我得加 `?v=<时间戳>` 之类的参数才能破。

所以：**如果你会覆盖更新同名文件，请在文档里说明**，我接线时就带上版本参数。

**版权**

用户说测试阶段不考虑，我按此执行。但如果以后正经上线，饥荒的美术资源是 Klei 的，
到时值得再确认一次 —— 这个判断我不替用户做。
