这一篇只解决一件事：**从落地到第一个天亮，怎么不死。** 饥荒的新手死亡率有一大半集中在前两个夜晚，原因几乎只有一个 —— 天黑之前没有光源。

## 一、落地先做三件事

刚进游戏别急着跑图，先在出生点附近把这几样凑齐。地上的东西直接捡，不需要工具：

| 目标 | 数量 | 用途 |
|---|---|---|
| 树枝 | 20 以上 | 火把、工具手柄 |
| 草 | 20 以上 | 火把、营火、草甲 |
| 燧石 | 至少 2 个 | 斧头、镐子 |
| 浆果 / 胡萝卜 | 见着就捡 | 食物 |

树枝和草在草原地形一片一片地长，几分钟就能凑够。燧石是散在地上的小石块，**只有开局这几天好捡**（它不可再生），见到就收。

顺手记一下地形：哪里有牛群、哪里有猪人、哪里是矿区。后面建家全靠这份记忆。

## 二、黄昏之前必须做出光

这是这篇教程最重要的一段。

白天 → 黄昏 → 黑夜，三段是连续的。**黑夜一旦完全没有光源，会直接出现「查理」并秒掉你**，不管你有多少血、穿什么甲。所以：

- 用 `草 ×2 + 树枝 ×2` 做**火把**，这个配方不需要任何科技，落地就能做
- 火把大约只能烧 2 分多钟，所以**至少做两根**，一根在手里、一根备用
- 想更保险就做**营火**（`草 ×3 + 木头 ×2`），能烧得久一些

先把斧头做出来（`树枝 ×1 + 燧石 ×1`），砍两棵树拿到木头，营火就有着落了。

> 顺序建议：捡树枝草 → 做斧头 → 砍树 → 做火把 + 营火 → 等天亮。

## 三、东西要烤熟了再吃

生肉、生浆果吃下去会掉理智，有些还会掉血。**所有食物先扔进火里烤**：

- 生浆果 → 烤浆果：饥饿回复更高，理智不掉
- 生肉 → 熟肉：安全的主食
- **怪物肉是个例外**：生的熟的都会掉血掉理智，别直接吃。正确用法是攒着，等做出烹饪锅之后当材料（一块怪物肉加三个浆果就是肉丸）

第一天不用纠结吃什么，吃饱就行。真正要规划食物是建家之后的事。

## 四、顺着地图边缘走

第一天的第二目标不是建家，是**认路**。

沿着地图边缘顺时针或逆时针走一圈，你会陆续看到：草原、森林、矿区、沼泽、猪人村、牛群。走的时候在脑子里（或纸上）记下位置，尤其注意：

- **金矿石**（带金色纹路的岩石）：敲它拿金块，做科学机器必须用
- **猪王 / 猪人村**：后面的肉食和猪皮来源
- **牛群**：牛毛、大肉，还能帮你打猎犬

不用走完整个地图，走到天黑前能回到安全的地方就行。

## 五、第一晚怎么过

天黑以后不要乱跑。找一个相对空旷的地方：

1. 放下营火，站在火边
2. 如果火快灭了就往里加草或木头
3. 别把营火放在树林里 —— 火焰会蔓延，把整片森林和你自己一起烧掉

撑到天亮，你就算过了新手第一关。

## 常见死法对照

| 死法 | 真正的原因 | 怎么避免 |
|---|---|---|
| 黑夜里被秒 | 没有光源 | 黄昏前一定做出火把 |
| 饿死 | 只顾着跑图没吃东西 | 饥饿条过半就找东西吃 |
| 被蜘蛛围死 | 黄昏后闯进蜘蛛巢 | 黄昏后远离成片的蜘蛛巢 |
| 理智崩溃被影怪打死 | 一直待在黑暗里 | 火边待着，白天采花回理智 |
| 烧死 / 烧掉家 | 营火放在可燃物旁边 | 营火放空地，长期用石头火坑 |

过了第一晚，下一步就是**选地方建家、把科技升上去** —— 那是第二篇的内容。
