活过第一晚之后，游戏的重心从"别死"变成"**把资源循环建起来**"。这一篇讲三件事：家安在哪、科技怎么升、四季怎么准备。

## 一、选址：新手只要记住一句话

**草原和桦树林的交界处，最好离牛群和猪人村不远。**

理由很实际：

- 草原上有成片的草和树枝丛，采集效率最高
- 桦树林提供木头
- 牛群能帮你顶猎犬（猎犬会周期性成群来袭）
- 猪人村提供肉和猪皮，猪王还能用金块换东西
- 交界处通常离矿区也不远，石头和金块好拿

**千万别把家安在这些地方：**

| 地方 | 为什么不行 |
|---|---|
| 沼泽中心 | 触手会主动攻击，而且攻击范围很大 |
| 蜘蛛巢旁边（除非你玩韦伯） | 黄昏后成群出来，家门口就是战场 |
| 孤立的水塘边 | 青蛙会偷你的东西 |
| 离资源太远的"风水宝地" | 每次采资源都要跑很久，效率才是新手最缺的东西 |

## 二、科技：一条清晰的升级路线

科技是解锁配方的唯一途径。站台旁边站一会儿就解锁，**解锁是一次性的**，之后离开也能继续做。

```
随手可做  →  科学机器  →  炼金引擎  →  暗影操纵者
（火把、斧头）  （背包、长矛）  （木甲、火腿棒）  （暗影系装备）
```

### 第一档：科学机器

`木头 ×4 + 石头 ×4 + 金块 ×1`，随手可做。

金块要靠镐子敲金矿石，所以流程是：捡燧石做镐子 → 敲金矿 → 回来做科学机器。

**优先解锁这几样：**

- **背包**：多背一格是一格，前期最实用的东西
- **铲子**：把野外的草、树枝、浆果丛整株挖回家种
- **长矛**（`树枝 ×2 + 绳 ×1 + 燧石 ×1`）：伤害 34，基础防身武器
- **木甲**（`木头 ×8 + 绳 ×2`）：吸收 80% 伤害，这是保命的关键

### 第二档：炼金引擎

`木头 ×6 + 石头 ×4 + 金块 ×2`，需要先站在科学机器旁解锁。

站到它旁边，你能做出这一阶段最重要的几样东西：

- **烹饪锅**（`树枝 ×6 + 木炭 ×6 + 草 ×6`）：食物问题的终点
- **冰箱**（`齿轮 ×2 + 金块 ×1 + 石头 ×1`）：大幅延缓食物腐烂
- **猪皮帽**（`猪皮 ×1 + 绳 ×1`）：头部护甲，和木甲一起穿就是标准战斗装备
- **火腿棒**（`猪皮 ×2 + 绳 ×1 + 怪物肉 ×2`）：伤害 59 的强力武器

木炭的拿法：**用火烧树**，烧完地上会留下木炭。别在基地附近烧。

## 三、烹饪锅：食物问题的终点

有了烹饪锅，食物就从"到处捡"变成"按配方生产"。

一次投入 **4 个食材**，结果由食材的"肉度 / 菜度 / 果度 / 蛋度"组合决定。新手只要记住两个配方：

| 料理 | 配方 | 效果 |
|---|---|---|
| **肉丸** | 肉 ×1 + 任意填充 ×3 | 饥饿 +62.5，性价比最高 |
| **肉汤** | 肉度 ≥ 3 | 饥饿 +150，肉多的时候用 |

**肉丸的经典做法是 `怪物肉 ×1 + 浆果 ×3`** —— 这一招同时解决了两个问题：怪物肉不能直接吃，浆果单吃回复又太少。做完之后怪物肉的负面效果就没了。

想做回血料理就需要火龙果（种田获得），火龙果派能回 40 点生命，是很关键的东西。

## 四、四季：每个季节都有自己的杀手

秋天是最温和的季节，也是新手开局的首选。但**每一个季节都会带来一种新的死法**，提前准备才活得久。

| 季节 | 主要威胁 | 提前准备 |
|---|---|---|
| **秋** | 几乎没有，抓紧建家囤物资 | 科技、烹饪锅、食物储备 |
| **冬** | 持续受冻；巨鹿会出现 | 保暖石、保暖衣物、火源储备 |
| **春** | 持续下雨导致潮湿；青蛙雨 | 雨伞或眼球伞 |
| **夏** | 持续过热；**建筑会自燃** | 降温装备 + 雪球发射器 |

其中夏天最容易被忽视：**自燃会烧掉你辛苦建的整个基地**。在入夏前把雪球发射器做出来盖住关键建筑，否则可能一夜之间全没了。

## 五、建家之后该做什么

一个运转正常的基地大概长这样：

- 火坑在中间（比营火安全，不会引燃周围）
- 科学机器 / 炼金引擎 / 暗影操纵者放一起，做东西不用跑
- 烹饪锅 + 冰箱组成食物区
- 附近有移植过来的草、树枝、浆果丛（用铲子挖回来种）
- 外围铺一圈犬牙陷阱，或者把猎犬引到牛群那边

做到这一套，你就从"活过第一晚"进入"稳定生存"了。下一步是过一个完整的冬天 —— 第三篇讲这个。
