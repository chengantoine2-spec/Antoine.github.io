冬天是新手遇到的第一个"真正的考验"。它同时从三个方向压过来：**温度、食物、Boss**。这一篇按这个顺序讲清楚。

## 一、温度：先解决保暖

冬天最直接的死因是**冻伤**。角色体温掉到一定程度会持续掉血，而且掉得很快。

保暖靠三样东西，从便宜到讲究：

| 装备 / 物品 | 做法 | 效果 |
|---|---|---|
| **营火 / 火坑** | 营火随手做；火坑 `石头 ×12 + 木头 ×2` | 靠近回温，是主力 |
| **保温石** | `石头 ×10 + 镐子 ×1 + 燧石 ×3`（炼金引擎） | 烤热后随身带，延缓受冻 |
| **保暖衣物** | 牛毛类制品（剃牛毛获得） | 降低体温流失速度 |

**出门前的标准动作**：把保温石放在火边烤热，再带在身上出门。回来之后继续烤，循环用。这是最省事、性价比最高的过冬办法。

另外冬天白天变短、黑夜变长，**光源储备要比秋天多得多**，别出现"天黑在野外、火把不够"的情况。

## 二、食物：冬天田里不长东西

冬天农场基本停产，浆果丛也不再结果。所以食物必须在入冬前准备好：

- **囤耐放的食物**：蜂蜜（约 40 天）、肉干这类不容易坏的优先
- **靠冰箱**：有了冰箱，食物的腐烂速度会大幅下降
- **打猎**：冬天仍然可以打牛、打蜘蛛、钓鱼，肉类来源不断
- **烹饪锅别停**：怪物肉 + 浆果的肉丸组合在冬天照样能用

一个常被忽视的点：**冬天饥饿掉得并不会变慢，但因为食物变少，很容易陷入"不敢吃东西"的恶性循环**。该吃就吃，吃光了再去打。

## 三、巨鹿（独眼巨鹿）：冬天最大的威胁

巨鹿会在冬季后期出现，**主动朝你的基地方向走，沿途拆掉建筑和树木**。如果你把家建得很好，它就是把家拆掉的那个东西。

### 关键数值

- 生命 2000
- 伤害 150（这一下很痛，必须穿甲）
- 会拆建筑，攻击范围大

### 打之前的准备

| 准备 | 说明 |
|---|---|
| **护甲** | 木甲 + 猪皮帽，两件都穿（吸收 80%） |
| **武器** | 长矛起步，有火腿棒更好 |
| **回血** | 治疗药膏或回血料理，至少带几份 |
| **走位** | 学会打一两下就退开，硬拼很容易死 |

### 三种处理思路

**1. 引走（推荐给新手）**

别在家里打。发现巨鹿来了就往远处跑，把它引到**沼泽（触手）、牛群、树林**这些地方，让它和其它生物互斗。它掉血，你不用冒险。

**2. 引到牛群 / 猪人处**

牛群和猪人会攻击入侵者，能帮你分担大量输出。你只需要在旁边补刀。

**3. 硬拼（有装备之后）**

穿齐木甲 + 猪皮帽，拿火腿棒，打一下退一步。生命掉到一半就吃药膏。伤害 150 意味着不穿甲两三下就没了 —— **没有护甲千万别硬拼**。

### 掉落

- **独眼巨鹿眼球**：用来做**眼球伞**，防雨效果全游戏最强
- 大肉

眼球伞的价值在春天会体现出来：春雨持续不断，没有防雨装备会一直潮湿、掉理智。所以打巨鹿不只是为了活过冬天，也是为了准备下一个季节。

## 四、冬天该做的事（不只是活着）

冬天虽然难受，但也是**做长期建设的好时机**，因为外面的威胁相对集中、你有时间待在家里：

- 把科学机器升级到炼金引擎，解锁木甲、火腿棒、冰箱
- 修整基地布局，把移植的草和树枝种好
- 挖矿囤石头、金块
- 打蜘蛛囤蜘蛛丝和怪物肉

**冬天不是用来熬的，是用来补基建的。** 熬过第一个冬天之后，你会发现后面几个季节都从容很多。

## 五、冬天检查清单

入冬前逐条确认：

- [ ] 保温石做好了，并且知道要烤热再用
- [ ] 有至少一件保暖衣物
- [ ] 食物储备够撑过冬天，或者有稳定肉源
- [ ] 火坑能持续供燃料
- [ ] 木甲 + 猪皮帽各有一套
- [ ] 有长矛或更好的武器
- [ ] 知道巨鹿来了往哪引

七条都打勾，冬天基本稳了。
