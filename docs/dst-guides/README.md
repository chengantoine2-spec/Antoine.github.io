# 饥荒 Wiki 新手教程（稿件）

这里放着准备发布到博客的三篇新手教程。它们**不是** Wiki 窗口里那种结构化条目，
而是完整的长文 —— 所以按「文章 = GitHub Issue」的约定发布，打上 `wiki` 标签。

## 三篇是什么

| 文件 | 讲什么 |
|---|---|
| `01-第一晚怎么活下来.md` | 落地收集、黄昏前必须做出光、食物要烤熟、沿地图边缘认路、第一晚怎么过、常见死法对照 |
| `02-建家选址与科技升级.md` | 选址一句话结论与禁区、科技升级路线、烹饪锅配方、四季各自的杀手、建家后的检查项 |
| `03-准备过冬与对付巨鹿.md` | 保暖三件套、冬天的食物、巨鹿的数值与三种处理思路、冬天该补的基建、入冬检查清单 |

每篇开头都有 front-matter：

```
---
title: 【新手教程 1】第一晚怎么活下来
labels: wiki, 新手教程
---
```

`wiki` 这个标签是**关键**：Wiki 窗口的「新手教程」区就是按它来筛文章的，
缺了它教程不会出现在 Wiki 里。

## 怎么发布

### 方式一：一条命令（推荐）

需要一个能写 Issues 的 GitHub Token（fine-grained 的 Issues 读写，或 classic 的 `public_repo`）：

```powershell
# PowerShell
$env:GH_TOKEN = "ghp_xxx"
node docs/dst-guides/publish.mjs --dry     # 先干跑，确认要发哪几篇
node docs/dst-guides/publish.mjs           # 真发
```

```bash
# bash
GH_TOKEN=ghp_xxx node docs/dst-guides/publish.mjs
```

脚本行为：

- 自动补上 `wiki` 标签（即使 front-matter 里漏了）
- 已存在同名文章时**默认跳过**，不会重复创建；要覆盖加 `--update`
- 只读 front-matter 里的 `title` 与 `labels`，正文原样发布
- 只用 Node 内置能力，不引任何依赖

### 方式二：手工贴进「博客创作」窗口

1. 打开「博客创作」窗口，填好 Token
2. 点「新建文章」，标题照 front-matter 的 `title` 填
3. 点分类里的 **「饥荒 Wiki」**（会写入 `wiki` 标签）
4. 把 markdown 正文（`---` 之后的部分）整段贴进正文框
5. 发布

## 发布之后会怎样

- **Wiki 窗口 →「新手教程」区**：出现这些文章，可以搜索，点开看正文
- **博客窗口**：默认列表里**看不到**它们 —— `wiki` 文章被有意分流出去，
  免得教程把日常 / 项目淹掉；只有显式点「饥荒 Wiki」分类才会显示
- 内容仍然是一篇普通文章：可以编辑、下架、删除，图片走 img 分支

## 注意

- 文章里的数值按当前联机版整理，游戏更新后可能变动
- 未认证访客有 10 分钟的博客缓存（`desktop.blog`），刚发布可能要多等一会儿或点一次「刷新」
- 教程正文和 Wiki 条目里的表述**不要互相抄**：条文放 Wiki（可被反查、可跳转），
  长文放教程（有叙述顺序）。两边重复维护一定会对不上。
